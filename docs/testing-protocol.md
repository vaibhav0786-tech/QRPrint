# Testing Protocol

Use an isolated test merchant, real supported printer in a controlled environment, provider sandbox, and non-sensitive documents. Verify: QR contains the merchant URL; upload rejects unsafe/oversized files and records actual page count; each specification maps to the selected profile; server quote matches active rule; payment webhook signature and idempotency work; only paid jobs reach the local SSE queue; a printer acknowledgement changes state; paper-out/offline jobs retry then fail visibly; collection tokens are unique; and daily paid transactions reconcile with provider settlement and completed/refunded jobs. Test authorization, replayed webhooks, disconnected merchant devices, duplicate status submissions, storage expiry, and customer refresh/retry paths.
